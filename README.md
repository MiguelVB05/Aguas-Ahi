# Aguas-Ahi
Aguas Ahi es una plataforma digital contra el desabasto de agua y abusos de piperos. Facilita compras vecinales colectivas, reduciendo el costo un 40%. Garantiza pagos seguros mediante escrow, liberándolos solo tras validar la entrega con códigos QR criptográficos y geolocalización. Este modelo íntegro impulsa los ODS 6, 10 y 16.
